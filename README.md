# متجر النخبة السعودي | منصة التجارة الإلكترونية المتكاملة (شبيه سلة)

نظام متجر إلكتروني سعودي فاخر ومتكامل وفق أعلى المعايير والمواصفات المطلوبة، يشمل **واجهة العميل (Storefront)** + **لوحة تحكم التاجر (Merchant Admin Dashboard)** + **محرك قاعدة بيانات تفاعلي (Database Layer)** + **نظام الفوترة الإلكترونية المعتمد من هيئة الزكاة والضريبة والجمارك (ZATCA)**.

---

## 🌟 مميزات النظام الأساسية

### 1. واجهة المتجر للعملاء (Customer Storefront - `index.html`)
* **هيدر متطور:** شريط إعلاني ترويجي علوي، شعار المتجر، محرك بحث فوري مع اقتراحات تلقائية (Live Autocomplete)، سلة تسوق ذكية مع عداد، وقائمة مفضلة.
* **بنرات ترويجية سلايدر (Hero Banners):** تصاميم فاخرة لشاشات العرض والعروض الحصرية.
* **شريط مزايا الثقة:** شحن مجاني لكافة مدن المملكة، منتجات أصلية 100%، دفع إلكتروني آمن، وفاتورة ضريبية فورية.
* **أقسام المنتجات:**
  * شبكة التصنيفات المميزة (عطور وبخور، ساعات ذكية، قهوة وضيافة، إكسسوارات).
  * قسم **عروض الصاعقة (Flash Deals)** مع عداد زمني تنازلي حي (Countdown Timer).
  * المنتجات الأكثر طلباً ومبيعاً (Best Sellers).
  * أحدث المنتجات (New Arrivals).
  * آراء وتقييمات العملاء الموثقة مع النجوم.
* **صفحة تفاصيل المنتج (PDP):**
  * معرض صور متعدد الزوايا مع مصغرات وتكبير (Gallery & Thumbnails).
  * كود SKU للمنتج وحالة التوفر بالمخزون.
  * محدد المتغيرات (الأحجام، الألوان) مع تحديث فوري للسعر والمخزون والصور.
  * تنبيه المخزون المنخفض التفاعلي ("سارع بالطلب! متبقي X قطع فقط").
  * زر الإضافة للسلة السريع وزر "شراء الآن" الفوري.
  * حاسبة موعد التوصيل المتوقع لمدن المملكة.
* **سلة التسوق الجانبية (Slide-over Cart Drawer):**
  * شريط تفاعلي لحساب الشحن المجاني المتبقي ("أضف بـ X ر.س للحصول على شحن مجاني").
  * إمكانية زيادة / إنقاص الكمية أو الحذف الفوري.
  * تطبيق كوبونات الخصم مع فحص فوري للصلاحية وقيمة الحد الأدنى.
* **صفحة إتمام الطلب الشاملة (Checkout):**
  * التحقق من رقم الجوال السعودي بصيغة `05xxxxxxxx`.
  * اختيار مدن المملكة (الرياض، جدة، الدمام، مكة، المدينة...).
  * طرق شحن وطنية (سمسا إكسبريس، أرامكس، مندوب فوري).
  * وسائل دفع سعودية معتمدة: **مدى (Mada)** مع محاكاة بطاقة تفاعلية، **Apple Pay**، بطاقات ائتمانية، **تمارا (تقسيط على 4 دفعات)**، والدفع عند الاستلام.
* **شاشة تأكيد الطلب والامتثال الضريبي (ZATCA):**
  * إنشاء رقم طلب فريد ورمز تتبع بوليصة الشحن.
  * **توليد رمز QR متوافق تماماً مع هيئة الزكاة والضريبة والجمارك (Base64 TLV Encoding)**.
  * زر لطباعة الفاتورة الضريبية الرسمية بضغطة واحدة.

---

### 2. لوحة تحكم التاجر الشاملة (Admin Dashboard - `admin.html`)
لوحة إدارة احترافية شبيهة بلوحة تحكم منصة سلة وزد:
1. **الرئيسية والإحصائيات:** إجمالي المبيعات، عدد الطلبات، عدد العملاء، تنبيهات نفاد المخزون، وجدول أحدث الطلبات.
2. **إدارة المنتجات (CRUD):** إضافة منتج جديد بمودال متكامل (الاسم، SKU، السعر قبل وبعد الخصم، تكلفة الشراء، المخزون، الشارة، الوصف، الصور)، مع إمكانية التعديل والحذف الفوري.
3. **إدارة التصنيفات:** تنظيم الأقسام الرئيسية والفرعية وصورها.
4. **إدارة المخزون والتنبيهات:** مراقبة الأرصدة وتعديل الكميات سريعاً بنقرة زر (+5, +20, -1).
5. **إدارة ومتابعة الطلبات:**
   - فرز الطلبات حسب الحالة (جديد، قيد التجهيز، تم الشحن، مكتمل، ملغي).
   - نافذة تفاصيل الطلب الكاملة.
   - تحديث حالة الطلب والدفع والشحن.
   - إضافة رقم بوليصة الشحن والتتبع.
   - زر مباشر لمراسلة العميل عبر **WhatsApp**.
   - طباعة **الفاتورة الضريبية المبسطة ZATCA** بصيغة رسمية جاهزة للطباعة والـ PDF.
6. **دليل العملاء:** استعراض العملاء، أرقام الجوالات، وإجمالي المشتريات.
7. **التسويق والكوبونات:** تفعيل وتعطيل أكواد الخصم والتحكم بنسب الخصم والحدود الدنيا.
8. **مخصص المظهر والثيم (Storefront Customizer):**
   - اختيار اللون الأساسي للمتجر (Primary Color Picker) وانعكاسه الفوري على الموقع.
   - التحكم بنص وتفعيل الشريط الإعلاني العلوي.
9. **الإعدادات والضرائب:** إدارة اسم المتجر، السجل التجاري، الرقم الضريبي المعتمد، وهاتف الدعم.
10. **سجل العمليات والنشاط (Audit Logs):** توثيق كافة العمليات الإدارية والمبيعات بالوقت والتاريخ.

## 🚀 طريقة التشغيل والتجربة

### الطريقة الأولى (المباشرة - بدون أي برامج):
يمكنك فتح ملف `index.html` في أي متصفح (مثل Google Chrome أو Microsoft Edge) لتصفح المتجر، أو فتح ملف `admin.html` للدخول مباشرة إلى لوحة تحكم التاجر!

### الطريقة الثانية (عبر الخادم المحلي الخفيف):
انقر بالزر الأيمن على ملف `server.ps1` واختر **Run with PowerShell**، وسيتم تشغيل الخادم فوراً على:
* **واجهة المتجر:** `http://localhost:8080/`
* **لوحة تحكم التاجر:** `http://localhost:8080/admin.html`
